# Cicerón en el navegador

`extension/` contiene la fuente de la extensión para Chrome, Brave y Edge. El instalador prepara la carpeta `00 EXTENSION/` y registra el puente local. El navegador requiere cargar esa carpeta manualmente en cada perfil.

El menú de la extensión ofrece **Abrir Cicerón**. Consultar el estado de Pausa Feed, activarlo, pausarlo y ajustar los selectores de X se hace desde **Cicerón → Navegador**. Si el puente se desconecta, se conserva la última orden recibida. Antes de recibir una orden, el bloqueo está activo.

Para instalar o recargar la extensión, consulta [LEEME.txt](../LEEME.txt). Para ejecutar las pruebas, consulta [DESARROLLO.md](../DESARROLLO.md).
